# 0001 — Isoler l'import du site

Le site existant est consulté exclusivement par GET. Chaque capture est écrite dans un répertoire distinct ; les octets bruts ne sont jamais remplacés. Les ressources normalisées, rapports et assets mobiles sont reconstruits séparément. Une importation ne devient distribuable qu'après revue éditoriale et contrôle d'intégrité.
